# SplotLabs covered projects

**Maintainer: Bartosz Tomczyk, a natural person.**
**Status: proposed coverage; not evidence of deployment. Reviewed 21 November 2026.**

These are the repositories to which the [SplotLabs Contribution Terms](https://github.com/splotlabs/.github/blob/main/CLA.md) are proposed to apply.

| Repository               | Contributions accepted to                                     | Signing and enforcement status |
| ------------------------ | ------------------------------------------------------------- | ------------------------------ |
| `splotlabs/splot`        | First-party code, tests and original documentation            | NOT DEPLOYED / NOT TESTED      |
| `splotlabs/splot-studio` | First-party desktop application, tests and documentation      | NOT DEPLOYED / NOT TESTED      |
| `splotlabs/website`      | First-party website source, copy and assets                   | NOT DEPLOYED / NOT TESTED      |
| `splotlabs/.github`      | First-party profile, policies and contribution infrastructure | NOT DEPLOYED / NOT TESTED      |

This register does not change any repository's software license, does not make any repository MIT-0, claims no ownership of third-party material and does not reach back to earlier contributions. The terms apply to a contribution only where its repository is listed here and published the terms when the contribution was submitted, or where the rights holder confirmed the contribution expressly.

Third-party mirrors, forks and specification copies inside a listed repository are not places for contributions under these terms.

A new repository is not covered merely because the signing service can access it. Add it here, link the contribution policy from it, give it an actual license, associate it with the terms in the service, protect its branches and test the result before accepting outside code. Changing this register does not amend terms that somebody has already accepted.
