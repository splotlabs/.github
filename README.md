# splotlabs/.github

This repository holds the public profile of the [splotlabs](https://github.com/splotlabs)
organization and its shared contribution and licensing policies.

## Profile

GitHub shows `profile/README.md` on the organization page. The text comes from the
[splot README](https://github.com/splotlabs/splot#readme). `avatar.png` is the organization
picture.

## Policies

| File                                                 | Purpose                                                                 |
| ---------------------------------------------------- | ----------------------------------------------------------------------- |
| [CONTRIBUTING.md](CONTRIBUTING.md)                   | Contribution policy. GitHub shows it in repositories without their own. |
| [CLA.md](CLA.md)                                     | Individual Contributor License Agreement. **Draft, not active.**        |
| [CLA-PRIVACY.md](CLA-PRIVACY.md)                     | Privacy notice for contributor licensing. **Draft.**                    |
| [LICENSING.md](LICENSING.md)                         | Who the licensor is and how the public license works.                   |
| [COMMERCIAL.md](COMMERCIAL.md)                       | Alternative commercial licensing.                                       |
| [COVERED-PROJECTS.md](COVERED-PROJECTS.md)           | Repositories the CLA is proposed to cover.                              |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | Default pull-request template.                                          |

These files do not license the software in other repositories. Each repository keeps its own
`LICENSE.md` and third-party notices. This repository has no license file of its own.
