# splotlabs/.github

This repository holds the public profile of the [splotlabs](https://github.com/splotlabs)
organization and its shared contribution and licensing policies.

## Profile

GitHub shows `profile/README.md` on the organization page. The text comes from the
[splot README](https://github.com/splotlabs/splot#readme). `avatar.png` is the organization
picture.

## Policies

| File                                                 | Purpose                                                                    |
| ---------------------------------------------------- | -------------------------------------------------------------------------- |
| [CONTRIBUTING.md](CONTRIBUTING.md)                   | Contribution policy. GitHub shows it in repositories without their own.    |
| [CLA.md](CLA.md)                                     | SplotLabs Contribution Terms, based on MIT-0. Version 2.0.                 |
| [LICENSES/MIT-0.txt](LICENSES/MIT-0.txt)             | Standard MIT No Attribution text that the contribution terms apply.        |
| [CLA-PRIVACY.md](CLA-PRIVACY.md)                     | Privacy notice for acceptance records. Version 2.0.                        |
| [cla-assistant/metadata](cla-assistant/metadata)     | The three form fields shown on the signing page. Source for the Gist file. |
| [LICENSING.md](LICENSING.md)                         | Who the licensor is and which terms apply to which material.               |
| [COMMERCIAL.md](COMMERCIAL.md)                       | Alternative commercial licensing.                                          |
| [COVERED-PROJECTS.md](COVERED-PROJECTS.md)           | Repositories the contribution terms are proposed to cover.                 |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | Default pull-request template.                                             |

`LICENSES/MIT-0.txt` applies only to contributions that their authors license under the
contribution terms. It is not the license of this repository or of any project. Each repository
keeps its own `LICENSE.md` and third-party notices. This repository has no license file of its
own.
